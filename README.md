# Smart Irrigation System using Arduino

## Overview
This project is a Smart Irrigation System designed to automate the watering process based on soil moisture levels. It uses an Arduino, soil moisture sensor, relay module, solar panel, and potentiometer to monitor soil conditions and control irrigation efficiently. The system helps conserve water and supports sustainable agricultural practices.

## Components Used
- Arduino Uno
- Soil Moisture Sensor
- Relay Module
- Solar Panel
- Potentiometer
- Breadboard
- Jumper Wires

## Working Principle
1. The soil moisture sensor continuously measures the moisture content of the soil.
2. The potentiometer is used to adjust the moisture threshold level.
3. When the soil moisture falls below the set threshold, the Arduino activates the relay.
4. The relay turns on the water pump (simulated load) to irrigate the soil.
5. Once sufficient moisture is detected, the Arduino deactivates the relay, stopping the irrigation process.
6. The solar panel provides renewable energy for the system.

## Features
- Automatic irrigation control
- Water conservation
- Adjustable moisture threshold
- Solar-powered operation
- Low-cost and easy to implement

## Circuit Components
- Soil Moisture Sensor → Input to Arduino
- Potentiometer → Threshold adjustment
- Relay Module → Pump control
- Solar Panel → Power source
- Arduino Uno → Central controller

## Applications
